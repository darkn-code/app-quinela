# Frontend

Documento de referencia para el agente frontend.

## Objetivo

Crear una app React + Vite mobile-first para la quiniela del Mundial.

## Vistas previstas

- Inicio.
- Registro o inicio de sesion.
- Lista de partidos.
- Captura de predicciones.
- Ranking general.
- Administracion simple para resultados, si se decide resolverla desde frontend.

## Lineamientos

- Priorizar celular.
- Usar CSS simple antes de introducir librerias.
- Mantener componentes pequenos y legibles.
- Centralizar cliente Supabase y manejo de sesion.
- No implementar reglas de seguridad solo en frontend.

## Pendiente

- Inicializar React + Vite.
- Definir estructura interna de componentes.
- Definir estrategia de rutas.
- Conectar variables `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY`.
